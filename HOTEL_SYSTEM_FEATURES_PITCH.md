# Hotel Management Website System

## Why Choose This System

This system is built for hotels that want a professional website, direct booking enquiries, online payment handling, and a clean admin panel without depending on multiple disconnected tools.

It helps hotel owners manage rooms, bookings, payments, enquiries, media, SEO, users, and operational records from one place. The system is designed to be practical for real hotel teams: owners get full control, admins can manage day-to-day operations, and staff can access only the areas they need.

## Core Website Features

- Modern responsive hotel website for mobile, tablet, and desktop.
- Home, About, Rooms, Events, Gallery, Contact, FAQ, Privacy Policy, and Terms pages.
- Room listing and room detail pages with pricing, images, amenities, policies, and booking form.
- Public booking flow with guest details, date selection, room selection, and payment support.
- Guest booking lookup page where customers can verify booking status using booking code plus email or phone.
- Contact enquiry forms for general hotel enquiries.
- Event enquiry forms for banquet, celebration, and event leads.
- Newsletter subscription support.
- SEO-friendly pages with metadata, canonical URLs, sitemap, robots.txt, and structured hotel schema.

## Admin Panel Features

- Secure admin login with owner-configurable rate limits.
- Role-based access for Owner, Admin, and Staff.
- Future-ready permission system where owner can customize role capabilities.
- Admin dashboard with live operational snapshot.
- Booking manager with booking status, guest details, room details, payment status, and notes.
- Booking calendar view for month-wise occupancy visibility.
- Manual booking creation for walk-ins, phone bookings, and offline reservations.
- Payment manager for Razorpay and Cashfree transactions.
- Payment recheck option to verify gateway status.
- Refund flow protected by OTP sent to hotel-domain owner/admin email.
- Refund allowed only for cancelled bookings.
- Booking status lock after refund is initiated, so records remain consistent.
- Receipt download for paid bookings.
- Configurable invoice prefix and tax details for receipts.
- Enquiry manager for customer messages.
- Room manager for creating and updating room information.
- Media library for managing website images.
- Gallery management.
- Events and banquet content management.
- Subscriber list management.
- Activity/audit logs for important admin actions.
- User management with Owner, Admin, and Staff roles.
- Last login tracking for admin users.
- Settings panel for hotel details, branding, SMTP, booking, payment gateway, SEO, and system controls.
- Developer mode toggle to show advanced SEO tools only when required.

## Payment Features

- Razorpay integration.
- Cashfree integration.
- Sandbox and production environment support.
- Encrypted storage for payment secrets and webhook secrets.
- Webhook URL support for payment status sync.
- Gateway transaction records.
- Payment payload and gateway response tracking for owner/debug use.
- Refund records with OTP email audit trail.
- Refund recheck support.
- Guest refund notification support.

## Security & Control

- Owner-only access for sensitive tools such as users, settings, activity logs, payment configuration, refunds, and SEO developer tools.
- Admin and staff see only relevant operational tools.
- Payment keys and secrets are encrypted in storage.
- Refund OTP must be sent to a domain-owned hotel email.
- Login rate limit is configurable by owner.
- Refund OTP resend and attempt limits are configurable by owner.
- Activity logs record sensitive admin operations.
- Bookings with paid or refunded transactions are protected from unsafe deletion.

## Business Benefits For Hotels

- Reduces dependency on third-party booking-only tools.
- Gives hotel owners direct control over enquiries and bookings.
- Improves trust with professional payment, receipt, and booking status flows.
- Helps guests verify their own booking without calling the hotel every time.
- Keeps staff access limited, reducing operational risk.
- Makes website content, rooms, events, media, and SEO easy to update.
- Supports both online gateway bookings and offline/manual bookings.
- Helps owners track payments, refunds, and admin actions from one place.
- Designed for future expansion into full user management, advanced permissions, reports, and integrations.
