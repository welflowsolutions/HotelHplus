# Hotel Management System - Client Feature Overview

## Website and Guest Experience

- Mobile responsive hotel website.
- Home, About, Rooms, Events, Gallery, Contact, FAQ, Privacy Policy, and Terms pages.
- Room detail pages with direct booking option.
- Public event enquiry form for weddings, parties, meetings, and other events.
- Guest booking lookup page where customers can verify their booking status.
- SEO-ready structure with sitemap, image sitemap, and robots.txt.
- Gallery images managed from admin.

## Room Booking System

- Online room booking from the website.
- Date-based room availability checking.
- Room type wise inventory, such as 15 Deluxe Rooms or 10 Executive Rooms.
- Multiple room booking support for families and groups.
- Guest capacity control per room type.
- Automatic price calculation based on nights and number of rooms.
- Server-side validation so users cannot manipulate price or room quantity from browser tools.
- Booking confirmation and guest communication support.
- Booking receipt download for customers.

## Admin Booking Management

- Admin dashboard for hotel operations.
- View and manage all room bookings.
- Booking calendar for quick date-wise overview.
- Manual booking creation from admin for phone/walk-in bookings.
- Booking status management.
- Receipt/invoice access from admin.
- Public booking lookup support for customer verification.

## Room Management

- Add, edit, and manage room types.
- Set room price, available room units, and guest capacity.
- Upload and manage room images.
- Control room visibility and booking availability.
- Delete protection and permission-based access for sensitive actions.

## Event Management

- Event enquiry management from admin.
- Event calendar for online and offline events.
- Create manual/offline events from admin.
- Manage event services and packages.
- Record manual advances received by cash, GPay, PhonePe, bank transfer, etc.
- Create online payment links for event advances.
- Share event payment links by WhatsApp, email, or copy link.
- Cancel pending event payment links.
- Download event payment receipts.

## Payment Gateway Management

- Razorpay integration.
- Cashfree integration.
- Sandbox and production mode support.
- Payment manager for all gateway transactions.
- Payment order ID and payment ID tracking.
- Gateway payment recheck option.
- Webhook logging for payment status updates.
- Separate payment records for bookings and events.

## Refund Management

- Refund option available only for cancelled bookings.
- Confirmed bookings do not show refund actions.
- OTP-protected refund process.
- OTP sent to hotel-domain owner/admin email.
- Refund OTP recipient is recorded for safety.
- Refund action is logged for audit.
- Guest refund notification email support.
- Booking remains cancelled after refund.

## GST, Billing, and Receipts

- GST invoice enable/disable option.
- GST rate, GST label, and GSTIN settings.
- GST rows shown on receipts only when GST is enabled.
- Receipt/invoice prefix setting.
- PDF receipt download for bookings and event payments.

## Email and Communication

- SMTP email configuration.
- Booking auto-reply email support.
- Event enquiry auto-reply email support.
- Event payment link email support.
- WhatsApp sharing support for event payment links.

## User and Permission Management

- Owner, Admin, and Staff roles.
- Create and manage admin users.
- Role-based access control.
- Owner-only access for sensitive data and delete actions.
- Permission overrides for future flexibility.
- Last login tracking support.
- Staff/admin restricted from technical payment and owner-only information.

## Activity and Audit Logs

- Settings change logs.
- Room edit/delete logs.
- Payment configuration logs.
- Refund action logs.
- Admin activity logs.
- Permission-controlled access to audit history.

## Media, Gallery, and Branding

- Hotel details management.
- Logo and favicon management.
- Branding settings.
- Media library for uploaded assets.
- Gallery management.

## Why Choose This System

- Built for real hotel operations, not only a brochure website.
- Handles rooms, events, payments, refunds, receipts, GST, and staff access in one place.
- Supports both online and offline business workflows.
- Protects sensitive owner-only actions with permissions and OTP.
- Prevents customer-side price and availability manipulation through server-side checks.
- Ready for future expansion into housekeeping, room assignment, CRM, reports, OTA integration, and multi-property management.
- Suitable for small and growing hotels that need a professional online booking and admin management system.
